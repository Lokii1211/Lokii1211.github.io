Basic wrappers simply feed a prompt into an LLM and stream the text. My systems employ stateful, deterministic multi-agent graphs (LangChain, LangGraph, n8n) equipped with fallback routing, strict schema validation, vector database memory (pgvector, ChromaDB), and sandboxed execution. For example, Viya AI utilizes a 4-stage arbitration pipeline that routes voice intents to specific financial tools with sub-2s latency across 5 Indian languages.
SmartDetect enforces a rigorous 5-Stage Arbitration Cascade:
  • Stage 1 (Primary Anchor): InsightFace ArcFace 512-d embedding matching (cosine similarity ≥ 0.56). Under the Face-Anchor principle, if a face is clearly seen but doesn't match, fallback Re-ID is blocked to eliminate identity confusion.
  • Stage 2 (Torso Metric): Torso HSV color distance ≤ 30 within a 10-minute temporal window.
  • Stage 3 (Deep Re-ID): OSNet 512-d body feature cosine similarity ≥ 0.68 within a 12-hour window.
  • Stage 4 (ID-Switch Guard): ByteTrack tracklet drops cached matches upon 2 consecutive contradictions (< 0.35).
